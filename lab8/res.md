# **Анализ результатов численного эксперимента**

Я запустил `heat2d_simple.py` с текущими параметрами:

\\[ a=1,\quad T=0.5,\quad N_x=N_y=40,\quad N_t=400. \\]

Программа завершилась успешно, рассчитала погрешности обоих методов и сохранила все 6 графиков в папку `graphs`.

## **1. Главный результат**

**Численный эксперимент подтверждает, что погрешность зависит от трёх сеточных параметров:**

\\[ E=E(\tau,h_x,h_y). \\]

При этом ожидаемые зависимости для используемых методов имеют вид:

| Метод                        | Зависимость погрешности     | Порядок по времени |
| ---------------------------- | --------------------------- | ------------------ |
| МПН — переменных направлений | \\(O(\tau^2+h_x^2+h_y^2)\\) | Второй             |
| МДШ — дробных шагов          | \\(O(\tau+h_x^2+h_y^2)\\)   | Первый             |

Это оценки сходимости при достаточно гладком решении и согласованном измельчении сетки, а не точные формулы для величины ошибки.

**Основное отличие:** при уменьшении временного шага вдвое погрешность МПН обычно уменьшается примерно в 4 раза, а МДШ — примерно в 2 раза, пока не начинает преобладать пространственная погрешность.

Для одинаковой основной сетки программа вывела:

| Момент времени | Погрешность МПН | Погрешность МДШ |
| -------------- | --------------- | --------------- |
| \\(t=0.1\\)    | 3.0250 · 10⁻⁵   | 2.7811 · 10⁻³   |
| \\(t=0.3\\)    | 1.9299 · 10⁻⁵   | 1.5430 · 10⁻³   |
| \\(t=0.5\\)    | 1.0631 · 10⁻⁵   | 8.4708 · 10⁻⁴   |

При \\(t=0.5\\) погрешность МПН оказалась примерно **в 80 раз меньше**, чем погрешность МДШ.

Это не универсальное соотношение между методами: оно получено именно для заданной задачи и выбранных параметров сетки.

## **2. Зависимость погрешности от временного шага&#x20;**\\(\tau\\)

Здесь \\(N_x=N_y=64\\), а временной шаг изменяется от \\(0.025\\) до \\(0.0015625\\).

| \\(\tau\\) | МПН          | МДШ          |
| ---------- | ------------ | ------------ |
| 0.025      | 3.159 · 10⁻⁴ | 1.592 · 10⁻² |
| 0.0125     | 7.958 · 10⁻⁵ | 8.215 · 10⁻³ |
| 0.00625    | 1.955 · 10⁻⁵ | 4.170 · 10⁻³ |
| 0.003125   | 4.627 · 10⁻⁶ | 2.105 · 10⁻³ |
| 0.0015625  | 3.531 · 10⁻⁶ | 1.060 · 10⁻³ |

**Что видно на графике?**

Для МПН при первых нескольких уменьшениях \\(\tau\\) вдвое погрешность снижается приблизительно в 4 раза. Например:

\\[ \frac{3.159\cdot10^{-4}}{7.958\cdot10^{-5}}\approx3.97. \\]

Это подтверждает квадратичную зависимость ошибки от временного шага:

\\[ E\_{\text{МПН}}\sim\tau^2. \\]

Для МДШ при уменьшении \\(\tau\\) вдвое погрешность снижается примерно вдвое:

\\[ \frac{8.215\cdot10^{-3}}{4.170\cdot10^{-3}}\approx1.97. \\]

То есть:

\\[ E\_{\text{МДШ}}\sim\tau. \\]

Однако при самых малых значениях \\(\tau\\) кривая МПН становится практически горизонтальной. Это означает, что дальнейшее уменьшение временного шага уже не обеспечивает прежнего выигрыша: заметной становится погрешность пространственной дискретизации.

**Вывод:** при фиксированной пространственной сетке уменьшать \\(\tau\\) бесконечно нецелесообразно. В некоторый момент необходимо уменьшать также \\(h_x\\) и \\(h_y\\).

## **3. Зависимость погрешности от&#x20;**\\(h_x\\)

Открыть график error_hx.png

Здесь \\(N_y=64\\), \\(N_t=1000\\), а изменяется только количество разбиений по \\(x\\).

| \\(h_x\\) | МПН          | МДШ          |
| --------- | ------------ | ------------ |
| 0.098175  | 1.760 · 10⁻⁴ | 4.464 · 10⁻⁴ |
| 0.049087  | 4.588 · 10⁻⁵ | 3.475 · 10⁻⁴ |
| 0.024544  | 1.261 · 10⁻⁵ | 3.408 · 10⁻⁴ |
| 0.012272  | 4.292 · 10⁻⁶ | 3.418 · 10⁻⁴ |

Для МПН наблюдается отчётливое снижение погрешности при уменьшении \\(h_x\\).

При первом уменьшении шага вдвое:

\\[ \frac{1.760\cdot10^{-4}}{4.588\cdot10^{-5}}\approx3.84. \\]

Это близко к теоретическому коэффициенту 4 для второго порядка точности.

Но у МДШ ситуация другая. После \\(h_x\approx0.05\\) график практически перестаёт снижаться. При последнем измельчении сетки ошибка даже немного возрастает.

Это не означает, что МДШ имеет нулевой порядок точности по \\(x\\).

**Причина:** при \\(N_t=1000\\) величина \\(\tau=0.0005\\) ещё достаточно велика, чтобы временная ошибка МДШ преобладала над пространственной. Уменьшение \\(h_x\\) уже мало влияет на общую погрешность.

## **4. Зависимость погрешности от&#x20;**\\(h_y\\)

Открыть график error_hy.png

Здесь фиксированы \\(N_x=64\\), \\(N_t=1000\\), меняется только \\(N_y\\).

| \\(h_y\\) | МПН          | МДШ          |
| --------- | ------------ | ------------ |
| 0.086643  | 9.950 · 10⁻⁵ | 3.926 · 10⁻⁴ |
| 0.043322  | 2.773 · 10⁻⁵ | 3.452 · 10⁻⁴ |
| 0.021661  | 9.063 · 10⁻⁶ | 3.422 · 10⁻⁴ |
| 0.010830  | 4.292 · 10⁻⁶ | 3.418 · 10⁻⁴ |

Для МПН при первом уменьшении \\(h_y\\) вдвое:

\\[ \frac{9.950\cdot10^{-5}}{2.773\cdot10^{-5}}\approx3.59. \\]

Это также согласуется со вторым порядком пространственной точности.

При дальнейшем уменьшении \\(h_y\\) коэффициент снижения ошибки становится меньше, поскольку сохраняется ошибка от фиксированного \\(h_x\\).

Для МДШ график снова выходит на плато около \\(3.4\cdot10^{-4}\\).

Следовательно, при выбранном \\(\tau\\) пространственную сходимость МДШ нельзя надёжно оценить по этому графику. Для её исследования нужно дополнительно уменьшить временной шаг, например увеличить `NT_SPACE`, или использовать более точную процедуру отделения временной ошибки.

## **5. Как изменяется погрешность со временем?**

Открыть график error_time.png

В начале вычислений погрешность равна нулю, поскольку начальное условие совпадает с точным решением:

\\[ u(x,y,0)=U(x,y,0). \\]

Затем ошибка накапливается, достигает максимума и начинает уменьшаться.

Такое поведение связано, в частности, с затуханием аналитического решения:

\\[ U(x,y,t)=\cos(2x)\cosh(y)e^{-3at}. \\]

При увеличении \\(t\\) само решение становится меньше, а вместе с ним в данном эксперименте уменьшается и абсолютная ошибка после начального максимума.

Важно: убывание ошибки со временем не означает автоматического повышения порядка точности метода.

На картах распределения ошибки при \\(t=0.5\\) видно, что погрешность неоднородна.

У МПН наибольшие ошибки расположены ближе к верхней границе \\(y=\ln2\\), преимущественно в центральной части области по \\(x\\).

У МДШ большие ошибки сосредоточены ближе к верхней левой части области. Это показывает, что ошибки двух схем имеют не только разную величину, но и разное пространственное распределение.

На границах с заданным значением функции ошибка практически нулевая, поскольку эти значения непосредственно задаются в программе. На верхней границе задана производная, поэтому значения функции там вычисляются приближённо.

## **7. Общий результат исследования**

Из результатов можно заключить, что при фиксированных \\(a\\) и \\(T\\) погрешность численного решения определяется сочетанием временного и пространственных шагов:

\\[ \boxed{ E\_{\text{МПН}}=O(\tau^2+h_x^2+h_y^2) } \\]

\\[ \boxed{ E\_{\text{МДШ}}=O(\tau+h_x^2+h_y^2) } \\]

Эксперименты по времени непосредственно подтверждают соответствующие порядки. Эксперименты по пространственным шагам подтверждают ожидаемую тенденцию для МПН, но из-за фиксированных остальных шагов не дают чистого второго порядка на всём исследуемом диапазоне. Для МДШ пространственный порядок по текущим графикам отдельно не установлен — его маскирует временная погрешность.

Это также объясняет, почему **все три шага нужно подбирать совместно**, а не пытаться улучшать точность бесконечным уменьшением одного параметра.

>
> Проведено исследование зависимости максимальной абсолютной погрешности от временного шага \\(\tau\\) и пространственных шагов \\(h_x\\), \\(h_y\\).
>
> Установлено, что при уменьшении временного шага вдвое погрешность метода переменных направлений в исследуемом диапазоне уменьшается приблизительно в четыре раза, что подтверждает второй порядок точности по времени. Для метода дробных шагов уменьшение погрешности составляет приблизительно два раза, что соответствует первому порядку точности.
>
> При уменьшении пространственных шагов погрешность метода переменных направлений также снижается. Полученные результаты согласуются со вторым порядком пространственной аппроксимации. Для метода дробных шагов выявлено ограничение эффективности измельчения пространственной сетки: при достаточно малых \\(h_x\\) и \\(h_y\\) общая погрешность практически перестаёт уменьшаться из-за преобладающего влияния временной дискретизации.
>
> Таким образом, точность численного решения определяется совместным влиянием временного и пространственных шагов. Уменьшение только одного сеточного параметра не всегда приводит к существенному повышению точности.
>
> При одинаковых параметрах основной сетки метод переменных направлений обеспечил примерно в 80 раз меньшую максимальную абсолютную погрешность, чем метод дробных шагов, при \\(t=0.5\\). Следовательно, для рассматриваемой задачи метод переменных направлений оказался более точным.

**Итоговая практическая рекомендация:** если главная цель — минимальная погрешность при разумном количестве временных шагов, для этой задачи стоит выбирать МПН. Для более строгой проверки пространственного порядка МДШ следует повторить эксперимент с существенно меньшим \\(\tau\\).
